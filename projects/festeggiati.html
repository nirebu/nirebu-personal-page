Directory of birthday promotions offered by businesses in Italy — find out who gives you something free (or discounted) on your birthday.

Visit festeggiati.it

What it is: an Italian-language, server-rendered directory with filterable, shareable listing pages (search, region, category), region landing pages for all 20 Italian regions, sitemap with paginated directory pages, and JSON-LD structured data (WebSite, FAQPage, ItemList).

Stack: Next.js 16 (App Router) + React 19 + Tailwind CSS v4.

Data pipeline: an EXA-powered discovery and verification pipeline feeds the directory — semantic search finds candidates, a free plain-HTTP stage checks live-page signals, a second EXA contents-API stage verifies JS-rendered pages, and a build script merges verified results with a hand-curated source of truth (deduplicated by domain).
